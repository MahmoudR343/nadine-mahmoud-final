## Updating the details

The date, start time, venue and Google Maps link live in **`config.js`**.

1. Open `config.js` here and click the pencil icon (Edit).
2. Change only the text between the quotation marks, e.g. `date: "2027-01-01"` or `time: "19:00"`.
3. Click **Commit changes**. The site updates within a minute or two.

## Notes

- The countdown runs to midnight Istanbul time on the date in `config.js`, unless `time` is filled in.
- The RSVP boxes are a design preview only: nothing is sent or saved.
- Music: `assets/song.mp3`. Set `playMusicOnOpen: false` in `config.js` so it only plays from the music button.
